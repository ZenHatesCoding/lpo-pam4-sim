1方案概要

适用场景与约束

  • LPO 光模块内部不做重 DSP，发送端均衡由 Host ASIC 承担，可用的均衡自由度只有 9-tap T-spaced 发送端 FFE 与 发送端模拟 CTLE 的双级直流增益。
  • 信道条件：奈奎斯特电插损 10～20 dB（Tx/Rx 对称），色散 0～28 ps/nm，差分群时延 0～5 ps，偏振角 0～45°。
  • 约束：在线调优阶段不得使用真实收端误码做决策（只能使用发送端可获得的物理量），且不允许出现任何一次“优化后比起点更差”。

方法构成

  1. 物理探针：向发送链注入单位脉冲，在入纤前截取 7-tap 等效发射 FIR，把 CTLE / PCB / Driver / MZM 的频响差异坍缩为 7 个波形采样。
  2. 双代理模型：Model A（7-tap FIR → log10 BER_MLSE，负责下降方向）与 Model B（11 维配置 → log10 BER_MLSE，负责安全否决），两者均为二阶多项式 Ridge 回归闭式解，纯 NumPy。
  3. 约束梯度下降：在 Model A 上做归一化投影梯度下降，方向由有限差分给出；每一步落地前须通过 Model B 的相对安全审查，并同时受信任域与梯度幅值门控约束。真实 BER 全量记录但不参与决策。
核心结论（完整数据见第 6 节）

3.2 物理探针与符号格对齐

  • 做法：注入理想单位脉冲，依次通过数字 Tx FFE → DAC 零阶保持 → 模拟 Tx CTLE → PCB（S4P）→ Driver 增益与带限 → MZM 电光带限，在入纤前按符号格对齐后截取 7 个 T 间隔抽头（前游标 2 / 主游标 1 / 后游标 4）。
  • 为什么用波形而非系数：同一组 FFE 系数在不同插损信道下的入纤波形不同。以系数为特征时，模型必须隐式学会信道特性，换环境即失配；以波形为特征时，信道差异已被探针吸收。
  • 对齐基准：S4P 为匹配不同目标插损需要作频率缩放，群时延随插损漂移（单位脉冲峰值位置实测：Base_IL10 为 idx = 1247，IL_Worst_20dB 为 idx = 238）。因此对齐基准由透传冲激确定、与 FFE/CTLE 系数无关，并按信道环境缓存，使同一环境下 FIR 是配置的光滑函数。
  • 成本：单次探针实测 15.1 ms（含 S4P 网络缓存），约为一次真实 BER 评估（2.61 s）的 1/173。

4.2 Stage-2 单步计算流程

  1. 安全参考：safety_ref = Model B(x₀)，红线 = safety_ref + 0.6（单位 log10，相对量）。
  2. 梯度：对 Model A 做 10 维有限差分，eps = 0.01，共 11 次评估。
  3. 梯度门控：|g| < 0.05 时判定曲面趋平并停止，避免沿拟合噪声继续移动。
  4. 方向：d = g / |g|（只使用方向，不使用幅值）。
  5. 步长：α_k = 0.02 × 0.92^k；CTLE 两维放大 20 倍以匹配量纲范围（±5 dB 对 ±0.3）。
  6. 投影：候选点裁剪至 x₀ ± [0.10 × 8, 3.0, 3.0] 与全局边界的交集。
  7. 安全审查：Model B 预测超过红线时步长折半重试（最多 20 次）；始终不通过则停止，不强行落地。
  8. 记账：写入代理预测与真实 BER_MLSE，供事后核验。
  9. 终止：位移 < 1e-4、或梯度门控触发、或达到步数上限。

4.4 可靠性依据

环节机制效果
特征侧以入纤波形（而非硬件参数）作为代理输入，信道频响差异被探针吸收同一模型可跨插损、色散、群时延变化复用，无需按环境重训

边界表现对策

覆盖范围限于已定义用例与器件参数 8 个应力用例；IL ≤ 20 dB、CD ≤ 28 ps/nm、DGD ≤ 5 ps 等 超出范围时重跑离线数据集（≈33 min）并重训（41 ms）；算法本身无需修改
