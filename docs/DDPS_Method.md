# DDPS v6 方法

## 1. 架构

DDPS v6：链路口径（5-tap FFE、CTLE 在 Tx IL 之后/Driver 之前、无 VGA、无 RMS 归一化、gain 由 per-case target_rms 物理驱动）。核心是 A/B 模型的分工：

- **Model A（方向代理）**：输入 = [7-tap Tx FIR 探针, drive_rms]（8 维波形域）→ log10(BER_MLSE) 条件均值。在线调优时拿不到收端 BER，只能拿发端探针，所以 A 的全部意义就是建立发端探针到收端 BER 的方向映射。
- **Model B（风险控制）**：输入 = [4 FFE 旁瓣, gDC, gDC2, drive_rms]（7 维参数域）→ log10(BER_MLSE) 保守上包络。基于调优后参数预测性能，按变差幅度拒绝候选。理想情况下全程不触发。
- **A/B 输入空间不同**（波形域 vs 参数域），误差来源相互独立。

## 2. 为什么 A 必须用探针、B 必须用参数

本质上如果能拿到收端 MLSE BER，就不需要 A 模型——直接对收端 BER 做梯度下降即可。
但在线调优时拿不到收端 BER，只能拿到发端探针。因此必须建立发端探针到收端 BER 的映射关系，
只要方向对就够——这就是 A 的全部意义。A 拿不到参数向量本身，参数向量是梯度下降直接操作的对象。

B 才是风险控制器：基于调优后的参数预测性能，根据性能变差幅度拒绝某些假设。
如果梯度下降做得正确，B 全程都不会触发拒绝。B 本质上是给未来跳出局部最优的启发式算法
预留的保护锁。

## 3. 梯度下降的链式法则

梯度不直接对参数求导，而是通过 A 的链式法则：

```
∂BER/∂param_i = Σ_j (∂A/∂probe_j) × (∂probe_j/∂param_i)
```

实现为 6 维中心差分：对每个参数 i 做 ±eps 扰动 → 重算探针（7-tap FIR + drive_rms）→
查 Model A → 得 ΔBER。每次梯度 = 7 次评估（1 基准 + 6 维扰动，每次 = 1 探针 + 1 A 前向）。

**关键**：扰动 CTLE 参数时必须把 gdc/gdc2 写入 config 再提取探针，否则探针对 CTLE 扰动无响应，CTLE 维梯度恒为 0。

## 4. gain 维：per-case target_rms 物理驱动

gain 不在 A 或 B 的输入里。每个用例单独细粒度扫描标定 target_rms
（0.06~0.22V，步长 0.005），在线调优时每步解析调到该用例的 target_rms：

```
gain = gain_ref × (target_rms / rms_measured)
```

## 5. 安全红线

红线 = **当前已知最优点**的 Model B 预测 BER × (1 + MAX_DEGRADE_FRAC)。

不用种子点的 B 预测（B 用基线训练，漂移环境绝对值不可信）。每步若 B 预测改善，
红线跟着下移——B 单调下降时红线永不触发。若 B 预测突然变差（方向错），红线才挡住该步。

实测 15 用例 153 步 0 劣化，红线全程未触发拦截——证明 Model A 方向已足够好，B 的价值是"保险"而非"必需"。

## 6. 数据集

只用基线环境 Base_IL10x10 的 2001 点，gain 倍率在 [0.40, 0.90] 窄带采样
（围绕 Base 的 per-case 最优 ×0.631）。数据集同时记录探针特征（tx_fir_0..6, drive_rms）
和参数坐标（x_0..x_5）供 A/B 分别训练。

非基线环境训练时（如 IL20x20），先用贝叶斯优化在该环境上搜全局最优种子点
（`optimizers/bo_search_il20.py`），再用 `--seed-config` 覆盖种子点，
在该种子点邻域采样数据集。

## 7. 模型指标（基线训练）

- Model A（探针 8 维）：R²=0.93, Spearman=0.97
- Model B（参数 7 维）：R²=0.91, Spearman=0.95, ρ=1.6
- Model A 局部方向 w_hit=1.00（6 维全部正确），corr=+0.93

## 8. 结果（15 用例，262144 符号 × 3 种子）

- 15/15 改善，0/153 步劣于种子
- 平均改善 ×5.16（最高 ×39.44 IL20x20）
- CTLE 激活 12/15（gDC 0→±2.5，gDC2 0→±2.7）
- A-only 与 A+B 结果完全一致（B 红线全程未触发）

## 9. 三组训练对比实验

同一套 v6 架构，唯一变量是训练环境与种子点：

| 组 | 训练环境 | 种子点 | 平均改善 | 正向 | 劣化步 |
|----|---------|--------|---------|------|--------|
| A 基线 | Base_IL10x10 | 工程标定 (gDC2=0) | ×5.16 | 15/15 | 0 |
| B IL20(BO种子) | IL20x20 | BO寻优 (gDC2=-4.95) | ×2.66 | 14/15 | 11 |
| C IL20(GD种子) | IL20x20 | 梯度下降终点 (gDC2=-2.66) | ×6.67 | 12/15 | 41 |

- 组 C 重损环境最优（Comb_IL20x20 ×57.08），但退步最多
- 组 B 低损环境早停，泛化性下降
- **结论**：低损环境训练 + 工程标定种子的组合泛化性最好

## 10. 已知边界

1. 恶劣场景绝对 BER 仍在 1e-2 量级（IL20x20=1.52e-3, Comb_IL20x20=7.52e-3）。
2. per-case target_rms 是离线标定的，换器件需重跑扫描。
3. 高损环境训练的模型泛化性不如低损环境训练。
4. Model A 的绝对标定弱（只用于方向），步长由各维箱宽决定。
