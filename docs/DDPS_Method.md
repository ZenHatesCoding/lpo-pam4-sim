# DDPS 方法

## 1. 架构

DDPS：链路口径（5-tap FFE、Tx CTLE 为 OIF 2Z3P peaking 拓扑、Rx CTLE 固定 gDC=6/gDC2=3、Tx 路径无 VGA/无 RMS 归一化（Rx 侧 TIA 一层物理 AGC）、gain 为第 7 个搜索维）。核心是 A/B 模型的分工：

- **Model A（方向代理）**：输入 = [7-tap Tx FIR 探针, drive_rms]（8 维波形域）→ log10(BER_MLSE) 条件均值。在线调优时拿不到收端 BER，只能拿发端探针，所以 A 的全部意义就是建立发端探针到收端 BER 的方向映射。
- **Model B（风险控制）**：输入 = [4 FFE 旁瓣, gDC, gDC2, drive_rms]（7 维参数域）→ log10(BER_MLSE) 保守上包络。基于调优后参数预测性能，按变差幅度拒绝候选。理想情况下全程不触发。
- **A/B 输入空间不同**（波形域 vs 参数域），误差来源相互独立。

## 2. 为什么 A 必须用探针、B 必须用参数

本质上如果能拿到收端 MLSE BER，就不需要 A 模型——直接对收端 BER 做梯度下降即可。
但在线调优时拿不到收端 BER，只能拿到发端探针。因此必须建立发端探针到收端 BER 的映射关系，
只要方向对就够——这就是 A 的全部意义。A 拿不到参数向量本身，参数向量是梯度下降直接操作的对象。

B 才是风险控制器：基于调优后的参数预测性能，根据性能变差幅度拒绝某些假设。
如果梯度下降做得正确，B 全程都不会触发拒绝。B 本质上是给未来跳出局部最优的启发式算法
预留的保护锁。

## 3. 梯度估计：gain 维解析 + shape 维割线（除第 0 步外零试探态）

梯度不直接对参数求导，而是通过 A 的链式法则（方向由 Model A 提供）：

```
∂BER/∂param_i = Σ_j (∂A/∂probe_j) × (∂probe_j/∂param_i)
```

在线实现把 7 个搜索维拆成「gain 维解析、shape 维割线」，除第 0 步外绝不为测梯度进入任何 x±ε 过渡态：

1. **gain 维：解析梯度，0 试探**——Model A 的 8 维探针 = [绝对标定 7-tap Tx FIR, drive_rms]，driver_gain 是 Tx 链末尾的标量乘子，故 8 个特征都严格 ∝ gain。设 `u_gain = log10(gain / DRIVER_GAIN_NOMINAL)`，则 gain = g0·10^u ⇒ `∂feat_j/∂u = ln(10)·feat_j`，于是
   `∂A/∂u_gain = ln(10) · Σ_j (∂A/∂feat_j) · feat_j`
   其中 ∂A/∂feat_j 由 Model A 的解析多项式梯度给出（WhiteBoxRidge 二阶多项式闭式求导，输入标准化后 ÷sd 换算回原始量纲）。每步用**当前落点探针**现算，0 试探、永不陈旧。
2. **shape 维：第 0 步一次性中心差分 + 此后割线更新**——第 0 步对 6 个 shape 维（4 FFE 旁瓣 + gDC + gDC2）逐维做 ±eps 扰动 → 重算探针 → 查 Model A → 得 `gᵢ=(A⁺−A⁻)/(2·epsᵢ)`（eps 分档 0.01 / 0.1；这是唯一一轮 12 探针）。此后每步用割线（Broyden "good"）更新
   `g_{k+1}[:6] = g_k[:6] + (ΔA − g_gain·Δx_gain − g_k[:6]ᵀΔx[:6])·Δx[:6] / ‖Δx[:6]‖²`
   （Δx = 上一步实际位移、ΔA = Model A 预测变化；割线方程剔除 gain 的已知贡献）。shape 维只用历史落点探针做免费算术。

**为什么 gain 维不割线、用解析**：Broyden 秩-1 更新只沿「已走过方向」修正梯度；gain 维单步位移小、方向分量弱，会被压塌（实测纯割线 gain 维卡 ×0.302、u_gain=−0.52 不动、梯度幅值跌破门控冻结，而 shape 维在同样操作下正常收敛）。gain 维改用解析梯度后正常爬升并收敛到链式水平——根因不是「gain 不适合梯度下降」，也不是「缩放不匹配」，而是割线秩-1 更新对弱方向分量的固有压塌。

边界：Model A 只消费**历史落点 + 第 0 步 12 个 shape 试探态**的探针结果（第 0 步之后不再制造任何参数微扰态）；Model B 的输入是**新参数**，在 apply 到系统前即可预测 → 先验拒绝候选。真实 BER 只记账、不参与决策。

**试探步 BER 记录**：只有第 0 步 12 个 shape 维 ±ε 微扰态是真实在线系统里的参数微扰，这些态自身的端到端 MLSE BER 被逐一记录（只用于透明度核验、不参与方向），产出 `probes_<用例>.csv`（每用例固定 12 行、step=0）。第 1 步起 live 链路每步只短暂停留在已落地工作点。

**关键**：扰动 CTLE 参数时必须把 gdc/gdc2 写入 config 再提取探针，否则探针对 CTLE 扰动无响应，CTLE 维梯度恒为 0。

## 4. gain 维：第 7 个搜索维

gain 是第 7 个搜索维（`u_gain = log10(gain / 0.3399)`，标称 `DRIVER_GAIN_NOMINAL = 0.3399`）。
它经 drive_rms 进入 A/B 的输入，在 ±0.30 dex 的参数箱信任域内参与梯度；形状/CTLE 信任域为 ±0.10 / ±3.0 dB。

每个用例的最优 gain 倍率通过离线 per-case target_rms 扫描标定（0.06~0.22V，步长 0.005，解析
`gain = gain_scan × (target_rms / rms_measured)`），作为初始化与验收的参照。在线调优从次优起点
（基线 BER ≈ 1e-4）出发，梯度把 gain 推到各用例最优倍率附近。

## 5. 安全红线

红线 = **当前已知最优点**的 Model B 预测 BER × (1 + MAX_DEGRADE_FRAC)。

不用种子点的 B 预测（B 用基线训练，非基线环境绝对值不可信）。每步若 B 预测改善，
红线跟着下移——B 预测单调下降时红线不会触发。若 B 预测突然变差（方向错），红线才挡住该步。

## 6. 数据集

只用基线环境 Base_IL10x10 的 2001 点，7 维 LHS（4 FFE 旁瓣 + gDC + gDC2 + u_gain），
gain 在 u 空间 [−0.70, +0.10] 均匀采样（覆盖全用例 per-case 最优 gain 邻域 ×0.20~×1.26）。
数据集同时记录探针特征（tx_fir_0..6, drive_rms）和参数坐标（x_0..x_5, drive_rms）供 A/B 分别训练。

## 7. 模型指标（基线训练，80/20 划分）

- Model A（探针 8 维）：R²=0.692, Spearman=0.884
- Model B（参数 7 维）：R²=0.702, Spearman=0.878, ρ=1.752

## 8. 结果（15 用例，4194304 符号 × 单种子 42）

- 15/15 改善、0 持平、0 退步；几何平均改善 ×33292（最高 IL20x20 ×453351）
- 起点种子 BER 1.3e-4（Base）~ 5.4e-2（IL20x20 极端插损），调优后最优 5.97e-8（0 错误检测底）~ 3.6e-7（高噪声）；11 用例到 0 错误检测底，4 个强损伤/高噪声用例到各自残差底（IL20x20 1.20e-7、Comb_IL20x20_CD15_DGD5 2.39e-7、HighNoise_IL16x16 2.39e-7、HighNoise_IL10x10 3.58e-7）
- 全程 225 步真实 BER，0 步劣于种子；gain 维从 ×0.325 出发推到各用例最优倍率 ×0.37~×0.65（强信号 ×0.37~×0.39、中高插损 ×0.42~×0.48、极端插损/高噪声 ×0.57~×0.65）
- 除第 0 步外全程零 ±ε 试探态；第 0 步 12 个 shape 维 ±ε 试探态各自端到端 MLSE BER 已逐条记录（交付件 §6.4 表 + 收敛图灰点），证明第 0 步梯度初始化试探确实会让链路短暂经过劣化工作点
- 与链式（每步中心差分）逐位一致：gain 解析梯度消除割线陈旧滞后，最硬联合用例 Comb_IL20x20_CD15_DGD5 与链式同为 2.39e-7

## 9. 已知边界

1. 强信号用例最优 BER 低于 2^22 点估计分辨率（0 错误，95% CL < 2.4e-7），只能给上界而非点估计。
2. per-case target_rms 是离线标定的，换器件需重跑扫描（≈20 min）。
3. 代理是局部模型，信任域外预测不可信；靠梯度门控 + 信任域投影 + B 相对红线三道约束，趋平即停。
4. Model A 的绝对标定弱（只用于方向），步长由各维箱宽决定。
