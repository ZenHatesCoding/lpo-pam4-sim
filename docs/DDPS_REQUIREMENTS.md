## 一、架构要求（不可改）

### 方向代理与在线搜索空间
- **方向代理（Model A）**：输入 = [7-tap Tx FIR 探针, drive_rms]（8 维波形域）→ log10(BER_MLSE) 条件均值。
  WhiteBoxRidge（二阶多项式 + L2 Ridge 闭式解，带解析梯度）。Stage 1 离线冻结，在线不重训、不重新标定。
- **Stage 1 同时训练并导出的参数域产物**（输入 = 4 FFE 旁瓣 + gDC + gDC2 + drive_rms）：作为离线产物随 Stage 1 冻结，
  **不在线使用**。在线方向只来自 8 维探针域的方向代理。
- **在线搜索向量 `x = [5 个 FFE 抽头, gDC, gDC2, u_gain]`，共 8 维**。5 个抽头地位相同、全部是自由搜索变量，
  **不带任何边界**、不做峰值和约束、不做离线扫描给初值。只有 CTLE 与 gain 保留物理量程：
  `gDC ∈ [0, 12] dB`、`gDC2 ∈ [0, 4] dB`、`gain/g₀ ∈ [10^−0.52, 10^0.6]`（`u_gain = log10(gain/0.3399)`）。
- **gain 维（第 8 维）用解析梯度，0 微扰**：8 维探针特征全部正比于 gain，
  `∂A/∂u_gain = ln(10)·Σ_j (∂A/∂feat_j)·feat_j`，每步用当前落点探针重算。
- **形状 7 维（5 个抽头 + gDC + gDC2）的梯度获取有三档，一键切换**：
  | 档 | 机制 | 每步 ±ε 微扰态 | 每用例真实评估（2^22 实测） |
  | --- | --- | --- | --- |
  | `full` | 每步对 7 个形状维做中心差分 | 14 | 225（15 落点 + 210 微扰） |
  | `rotate` | 每步只重算 2 个维（`(step·2+j) mod 7` 轮转），其余沿用上次实测值 | 4 | 85（15 + 70） |
  | `secant` | 只有第 0 步做一轮中心差分，此后 Broyden 秩一修正（0 微扰） | 0 | 29（15 + 14） |
  三档的第 0 步完全一致（14 个 ±ε 微扰态），共用同一起点、同一组归一化步长与门控、同一**固定 15 步**。
- **固定 15 步、代理档不做提前停止**（三档只有在相同步数下比较落点与代价才有意义；上板时间可预算）。
  direct 参照档保留边际停止（`MIN_GAIN_DEX = 0.01` dex，step > 0 才判）。

### 物理层（链路口径）
PAM4（电平 [-3,-1,1,3]，RMS = √5）→ 5-tap Tx FFE → DAC(ZOH,ENOB 5.5 量化噪声以 AWGN 注入，满量程=DAC 输出信号自身 max−min) → Tx IL(S4P) → +1mV 噪声 → Tx CTLE(gDC,gDC2, peaking) → Driver(gain) → Driver BW(40GHz) → MZM(Vπ=3,bias=2.25,ER=25dB) → 光纤 → PIN → TIA → Rx IL → +1mV 噪声 → Rx CTLE(固定 gDC=6/gDC2=3) → ADC(ENOB 5.5 量化噪声以 AWGN 注入，满量程=ADC 输出信号自身 max−min) → Rx FFE(22-tap,LMS) → Burg → MLSE(memory=1)。**Tx driver 路径无 VGA、无 RMS 归一化；Rx 侧只有 TIA 一层物理 AGC（目标 RMS = √5 ≈ 2.236 V）。** 量化噪声 σ = V_FS/(2^ENOB·√12)，由 SNR_q = 6.02·ENOB+1.76 dB（满量程正弦）推导。BER 为真逐位 Gray 计数。
- Tx CTLE 为 OIF 2Z3P peaking 拓扑（`gDC` = 高频 peaking gain，直流增益恒 0 dB；`gDC2` = LF shelf gain），零极点比 `fz=2.862/fp1=1.884/fp2=1/flf=40`。
- Rx CTLE 与 Tx 同一拓扑但参数固定（`gDC=6, gDC2=3`），不参与寻优。

### 关键常量
- `N_DIM=8`、`N_TAP=5`、`N_SHAPE=7`；`EPS_VEC = [0.01]×5 + [0.1, 0.1] + [0.05]`
- `STEP_SPAN = 2 × [TRUST_FFE]×5 + [TRUST_CTLE, TRUST_CTLE, GAIN_TRUST] = [0.20]×5 + [6.0, 6.0, 0.60]`
  （`TRUST_FFE=0.10`、`TRUST_CTLE=3.0`、`GAIN_TRUST=0.30`；**只是步长尺度，不是参数范围**）
- `GD_LR=0.05`、`ALPHA_DECAY=0.97`、`GROUP_GATE=1e-3`、`n_steps=15`、`ROTATE_K=2`
- `DRIVER_GAIN_NOMINAL=0.3399`；次优起点 8 维见 `result/seed_config_bad_*.json`（经 `apply_seed_config` 装载）
- `SEED_TAPS=[-0.034,-0.2987,0.6091,0,0.0582]`（仅作未提供 seed_config 时的兜底）
- `PEAK_SUM_LIMIT=0.8` 与 `construct_taps()` **只存在于 Stage-1 数据集采样**，在线不受此限

## 二、物理代价口径（不可违反）

- **探针不是算出来的**：要读到探针就必须把参数真的打到链路上。每个落点、每个 ±ε 微扰态都是链路真实经过的
  工作点，不能只记账落点。
- 每一次真实链路评估都必须落盘：`case_summary.csv` 的 `n_landed` / `n_probe_states` / `n_real_evals` /
  `max_probe_lb` / `max_probe_ber`，以及 `probes_<用例>.csv`（step / param / sign / 坐标 / 真实 BER）。
- 交付件给出任何"每用例成本"时，必须同时给**真实评估次数**（落地 + 微扰），不能只给时间或步数。
- **没有代理否决层**：在线方向只来自方向代理的梯度，候选点不做二次代理审查、不做轨迹信任域限制。
  落点是否变差由实测 BER 事后核验，并在交付件（6.3）逐条列出。

## 三、对比实验

### 三a、三档形状梯度对比（现役）
- 同一实现一键切换：`--grad-mode full|rotate|secant`（Python `_stage2_descent_proxy(grad_mode=…)`，
  C++ `stage2_descent_proxy(…, grad_mode, rotate_k, …)`）。
- 三档共用同一次优起点、同一 15 用例、同一 2^22 符号 / 单种子 42 协议、同一固定 15 步。
- 交付件必须并列呈现：三档的落点 BER（几何平均 / 相对 full / 打平数 / 最坏单例倍数）与每用例真实评估次数，
  由 `_rows_mode_cmp` / `_rows_eval_cost` 从结果目录实算，不手写数字。

### 三b、direct 参照（有回传通道时的参照，不是替代方案）
- 问题：现役方案假设**没有回传通道**；如果端到端 BER 可以回传，直接对真实目标做梯度下降能达到什么水平？
- 实现：`_grad_direct_chain()`（第 0 步全 8 维中心差分，16 个 ±ε 微扰态，目标 = 真实 log10 BER）
  + `_stage2_descent_direct()`（此后全 8 维 Broyden，0 微扰）。
- 与现役的差别只在目标与梯度来源：无代理 → 无解析 gain 梯度（gain 维也实测）、无代理否决层。
- 同 8 维搜索空间、同起点、同步长机制、同组门控、同 15 步上限；C++ 一比一复刻
  （`optimizer.hpp` `grad_direct_chain` / `stage2_descent_direct`，`cpp/main.cpp --method direct`）。
- 结果目录：`result/ddps_cpp_direct/`（2^22 全量）、`result/ddps_equiv_{py,cpp}_direct/`（2^18 等价参照）。
- 交付件呈现：6.2 收敛图组页签（三档 + direct）；6.5 对比节（结果对比 + 方案说明两个页签）；
  10.4 等价页签（四档 2^18 实算最大相对差表）。
- 判读：同协议并列呈现，谁好用谁；真实 BER 到 0 错误检测限后梯度信号消失、边际停止触发属固有属性，不是缺陷。

### 三c、已归档的历史对比实验
训练环境对比（基线 vs IL20x20 两种种子）、A-only vs A+B 否决层对比，都是历史时期的实验，结果已归档在
`archive/`；现役只有单套冻结方向代理 + 无否决层，不再做这两类对比。

## 四、交付件要求（AGENTS.md 硬规矩）

### 刷新工作流（每次刷新都走一遍，不是填表）
每次「刷新交付件」是一次站在读者视角的**全量审阅**，按固定顺序走四步：
1. **素材**：先盘点有没有合适素材——真实数据、可提取的机制细节、能讲过程的轨迹。缺素材先补素材（提取脚本/图），不带病动笔。
2. **组织**：内容组织形式先设计——结构、顺序、什么进正文什么进页签、机制讲过程还是讲结论。素材变了组织可能要跟着变。
3. **通盘看**：全量审阅现有编排——有没有过时、冗余、口径不一致（如新增档位后全文还是单一档口径）、文档内部自相矛盾的数字。哪怕只是填一个空，也要看它上下文还成不成立。
4. **呈现**：视觉优先、语言人话（细则见下）。

### 呈现细则
- **机制讲过程必须可视化**：梯度怎么来、微扰态怎么产生、每步怎么更新、模型怎么训练、数据怎么构建——这类"过程"用步进帧（walkthrough）、图解 SVG 或真实数据驱动的交互组件讲，不靠文字堆。HTML 交付件的意义就在这。交互组件必须打印友好（print CSS 全帧展开）。
- **数字克制**：不是有数字就专业。巨大倍数（约 >100×）读者无感——不单独甩数字，换成"从 X 到 Y"的人话锚点（如"每 8 千比特错 1 个 → 每 1700 万比特错不到 1 个"）或直接交给图（收敛曲线本身）。有感知的倍数（2×、4×、8×）可保留。每个留下的数字必须能回答"所以呢"。
- **去 AI 味**：短句。不堆排比、不写"值得注意的是"、不一句话三个从句。技术表述直给，图和表承担细节，文字负责把图串成故事。
- **读者自检**：读者第一次看这份材料、没有任何前置信息。看完应该知道"现在是什么、怎么工作的"，而不是被数字淹没。

### 资产负债表原则
- 只讲现状：系统现在是什么样、能干什么、结果数字是多少
- 不假设读者有前置信息，只看这一个材料就能看懂
- 不从"为什么改、怎么修"开始，不写排错过程
- 不提"上一版/前一版/v3/v4/v5"
- 不用"消融""锚点""上限参考"等对照实验语言

### 图的要求
- 图例必须清晰：figure 级统一图例，不要挤在子图内
- 每条线/每个点都要有明确标注
- 收敛图要有：Model A 预测曲线、实测 BER（落点）、±ε 微扰态（灰点）、种子线（本方案在线只有一层方向代理，没有风险红线层，图上不画红线）
- 四联图（最难用例）：收敛轨迹 + FFE 抽头对比 + CTLE 频响 + 探针 FIR
- 散点图按物理类别着色（基线/IL/CD/DGD/复合/高噪）
- 逐档出图：每个档的结果目录各自出图（`report_ddps.py --test-dir result/ddps_cpp_<档>`），交付件 6.2 用页签逐档切换

### 表的要求
- 每个表有真实数据，无占位行
- 列标题清晰（中文，带单位）

## 六、双后端分工与比对口径（不可违反）

- **Python 定原理，C++ 一比一复刻**（算法、物理层模型、参数、调优算法全部一致；见 `AGENTS.md`「开发方式」）。
- **比对口径**：Python 与 C++ 的等价性验证、收敛对比只在 **2^18 小点数低 SNR** 下做——唯一允许的比对口径，不允许在大点数/高 SNR 下比对。
- **规模仿真分工**：全量规模仿真（高 SNR 大点数，如 2^22 在线调优与全量评估）**只用通过比对的 C++ 入口**（`cpp/run_all_cases.py`，现役 `--backend wsl`，见下方「C++ 构建运行环境」）；**不允许用 Python 跑高 SNR 大点数**（`test_generalization.py` / `tools/run_parallel_envs.py` 等 Python 入口只用于小点数低 SNR 验证）。
- **比对工具**：`cpp/compare_traces.py` 逐步（用例 × 步 × 数值列）比对 trace，判据 `max_rel < 1e-9`。
  四个入口（full / rotate / secant / direct）均已通过 2^18 逐轨迹比对：
  full 1.42e-12、rotate 1.20e-12、secant 8.53e-12、direct 8.89e-13。
- **C++ 构建运行环境（2026-10-12 起）**：本机 Windows Smart App Control 强制模式拦截本地编译的无签名 exe（含 MinGW cc1plus 依赖的 libisl-23.dll 与既有 run_ddps.exe），Windows 侧编译运行路线不可用；现役路线 = WSL(Ubuntu) g++（`cpp/build_wsl.sh` 构建、`cpp/run_all_cases.py --backend wsl` 调度，产物/结果仍落 Windows 文件树受 git 跟踪）。源码纯标准 C++17，跨平台构建不影响数值行为，等价性以 2^18 比对为准。
