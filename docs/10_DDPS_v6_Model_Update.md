# 10. DDPS v6 模型与算法口径

> A/B 双代理恢复了正确分工：A=探针→BER（方向映射），B=参数→BER（风险控制）。

## 1. 一句话现状

DDPS v6：链路口径与 v5 一致（5-tap FFE、CTLE 在 Tx IL 之后/Driver 之前、无 VGA、无 RMS
归一化、gain 由 per-case target_rms 物理驱动）。**核心改变是 A/B 模型的分工恢复**：

- **Model A（方向代理）**：输入 = [7-tap Tx FIR 探针, drive_rms]（8 维波形域）→
  log10(BER_MLSE) 条件均值。在线调优时拿不到收端 BER，只能拿发端探针，
  所以 A 的全部意义就是建立发端探针到收端 BER 的方向映射。
- **Model B（风险控制）**：输入 = [4 FFE 旁瓣, gDC, gDC2, drive_rms]（7 维参数域）→
  log10(BER_MLSE) 保守上包络。基于调优后参数预测性能，按变差幅度拒绝候选。
  理想情况下全程不触发。
- **A/B 输入空间不同**（波形域 vs 参数域），误差来源相互独立。

## 2. 为什么 A 必须用探针、B 必须用参数

本质上如果能拿到收端 MLSE BER，就不需要 A 模型——直接对收端 BER 做梯度下降即可。
但在线调优时拿不到收端 BER，只能拿到发端探针。因此必须建立发端探针到收端 BER 的映射关系，
只要方向对就够——这就是 A 的全部意义。A 拿不到参数向量本身，参数向量是梯度下降直接操作的对象。

B 才是风险控制器：基于调优后的参数预测性能，根据性能变差幅度拒绝某些假设。
如果梯度下降做得正确，B 全程都不会触发拒绝。B 本质上是给未来跳出局部最优的启发式算法
预留的保护锁。

## 3. 梯度下降的链式法则

梯度不直接对参数求导，而是通过 A 的链式法则：

```
∂BER/∂param_i = Σ_j (∂A/∂probe_j) × (∂probe_j/∂param_i)
```

实现为 6 维中心差分：对每个参数 i 做 ±eps 扰动 → 重算探针（7-tap FIR + drive_rms）→
查 Model A → 得 ΔBER。每次梯度 = 7 次评估（1 基准 + 6 维扰动，每次 = 1 探针 + 1 A 前向）。

## 4. gain 维：per-case target_rms 物理驱动

gain 不在 A 或 B 的输入里。每个用例单独细粒度扫描标定 target_rms
（0.06~0.22V，步长 0.005），在线调优时每步解析调到该用例的 target_rms：

```
gain = gain_ref × (target_rms / rms_measured)
```

## 5. 数据集

只用基线环境 Base_IL10x10 的 2001 点，gain 倍率在 [0.40, 0.90] 窄带采样
（围绕 Base 的 per-case 最优 ×0.631）。数据集同时记录探针特征（tx_fir_0..6, drive_rms）
和参数坐标（x_0..x_5）供 A/B 分别训练。

## 6. 模型指标

- Model A（探针 8 维）：R²=0.724, Spearman=0.906
- Model B（参数 7 维）：R²=0.656, Spearman=0.896, ρ=1.718

## 7. 结果（15 用例，262144 符号 × 3 种子）

- 15/15 改善，0/15 终点劣于种子
- 平均改善 ×2.03
- 预测-实测正相关 11/15（中位 +0.48）

## 8. 已知边界

1. CTLE 组在多数用例未激活（gDC/gDC2 停在 0）——探针对 CTLE 直流增益的灵敏度
   低于对 FFE 旁瓣的灵敏度。后续可调 CTLE 中心差分步长或改用解析链式雅可比。
2. 恶劣场景绝对 BER 仍在 1e-2 量级（IL20x20=4.8e-2, Comb_IL20x20=6.9e-2）。
3. per-case target_rms 是离线标定的，换器件需重跑扫描。
4. Model A 的绝对标定弱（只用于方向），步长由各维箱宽决定。
