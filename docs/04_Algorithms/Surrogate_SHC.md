# Surrogate-Assisted Safe Hill Climbing (代理模型辅助安全爬山)

[返回算法总览](README.md)

> [!NOTE]
> 本算法是经典 SHC 的增强版，旨在为“瞎子摸象”的爬山引入空间记忆与物理预测防御，作为探究代理模型边界的对照组。

## 1. 原理与方案设计 (Principle & Scheme)

在线调优 (Online Tuning) 过程中，纯盲搜算法（如 SHC）在每次试错时都有跳崖的可能，这种物理试错代价在现网中是不可接受的。
为此，Surrogate_SHC 在每次物理下发系数前，会在“大脑”里先进行模拟推演。

### 逆距离权重预测模型 (IDW Surrogate)
由于 BER 曲面高度非线性，简单的线性回归极易陷入局部误判。我们采用了距离反比权重（IDW）算法。
对于一个给定的试探步 $x$，预测其性能 $y_{pred}(x)$：
$$ y_{pred}(x) = \frac{\sum w_i y_i}{\sum w_i} + P_{unc}(x) $$
其中：
- $y_i$ 是滑动窗口（最近 50 次物理下发）中记录的历史真实 BER。
- $w_i = \frac{1}{||x - x_i||^2 + \epsilon}$ 是距离平方的反比。
- $P_{unc}(x)$ 是**不确定性惩罚项**。如果该试探步远离所有已知的安全点，惩罚项会直接拉高预测代价。

**安全保证的核心逻辑**：如果候选解试图跳跃到未知领域，$P_{unc}$ 会因距离惩罚而拉响警报，将其阻挡在物理网卡之外。

### 逻辑推演拦截
算法每回合会在数学空间中产生 20 次随机候选步，并挑选**第一个在预测模型中低于安全红线（例如 $BER < 10^{-2}$）**的步进下发物理执行。如果预测全军覆没，它会主动退避，发出一个步幅仅为原本 10% 的极其微弱的探路针。

## 2. 代码现状 (Code Status)

- **代码路径**：[`surrogate_shc_optimizer.py`](../../surrogate_shc_optimizer.py)
- **底层架构**：纯 Numpy 实现。20 次逻辑推演在当前 CPU 仅需微秒级开销，完美契合在线计算资源限制。
- **状态**：保留作为代理模型的参照物。

## 3. 测试方法与结果 (Test Method & Results)

### 测试方法
执行统一脚本 `compare_optimizers.py` 进行 25 次计费评估对比。

### 结果客观指标
- **Best MLSE BER (寻优深度)**：`5.30e-05`，表现优于 SafeQCD，略逊于 TuRBO-Safe。
- **Max MLSE BER (安全性)**：`1.68e-02`。尽管加了距离惩罚防御，由于 IDW 模型缺乏严格的置信下界，在某些恶劣边界处依然没防住局部“越过红线”的问题（突破了 $10^{-2}$ 阈值）。这也正是我们后续转向 TuRBO-Safe 的原因。

## 4. 用法 (Usage)

在主仿真入口 `main.py` 或 `optimize_tx.py` 运行时，通过全局配置文件 `config.xlsx` 控制：
- 在 `tx` 表格中，设置 `optimizer_type = 'Surrogate_SHC'`。
