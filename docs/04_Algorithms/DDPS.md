# DDPS 数据驱动物理代理优化器 (Data-Driven Physical Surrogate)

[返回算法总览](README.md)

> [!NOTE]
> 高速光通信系统的在线调参面临着“试错成本极高”的根本痛点（例如，测试一次 1e-5 量级误码率需要传输百万级 symbol，耗时漫长；更严重的是如果探索到恶劣参数会导致链路直接掉锁）。
> DDPS 是一条**完全离线**的“数据驱动”寻优路线，其核心思想是：构建计算极快的特征代理模型（Surrogate），利用纯数学梯度下降瞬间找到最优方向，从而避免在真实的、缓慢的物理信道上进行盲目试错。

## 1. 算法设计思路：从源头讲起

传统的黑盒优化（如贝叶斯优化 BO 或遗传算法 GA）都是直接把 `[FFE系数, CTLE]` 扔进黑盒，看跑出来的真实 `BER` 是多少，再决定下一步怎么走。这种“End-to-End”的盲搜有两个致命缺陷：
1. **真实物理评估极慢**：算一次完整的 MLSE BER 涉及极其耗时的光纤色散卷积和维特比解码网格。
2. **高维空间稀疏**：9 维空间非常庞大，盲目撒点掉进“不掉锁区域”的概率极低。

**DDPS 的破局思路**：
我们观察到，发送端（Tx）均衡操作的本质，是改变了“**入纤前的物理冲激响应 (Tx FIR)**”。这个 Tx FIR 相比于 9 个冷冰冰的数字系数，包含了更多与最终收端眼图质量直接相关的**物理特征**。
如果我们能训练一个映射关系：`f(Tx FIR) -> 系统最终 BER`，那么我们在优化时，就不需要去跑那几百万个 symbol 过真实信道，而是只需要：
1. 算一下当前系数下的单脉冲 `Tx FIR`（极少量的矩阵乘法，瞬间完成）。
2. 把 `Tx FIR` 丢给模型 `f`，瞬间预测出相对的 `BER`。
3. 利用数学对这个模型求偏导，用梯度下降直接“滑”向最优解。

为了兼顾这种“特征代理”的高效性与“防止在线掉锁”的安全性，我们设计了**两阶段工作流 (Two-Stage)** 以及与之配套的 **Model A (指路)** 和 **Model B (护航)**。

## 2. 两阶段 (Two-Stage) 优化架构

### Stage 1: 离线探索与代理模型训练
Stage 1 的任务**不是**寻找最优解，而是“探明地形，积累数据”。
我们在一个已知的安全工作点 `x0` 附近进行拉丁超立方采样 (LHS)。通过在离线仿真器中对这些采样点进行全链路（包含光纤色散和 MLSE 解码）评估，收集一批 `[系数, Tx FIR, 真实BER]` 的数据。

### 两个模型的底层数学结构（非神经网络）
为了追求极致的执行速度、100% 的白盒可解释性以及未来在 DSP 芯片/微控制器上的轻量级部署，我们**没有使用任何深度学习黑盒模型或调用第三方库（如 sklearn）**。

两个模型均采用了**纯 Numpy 手写的二阶多项式 Ridge 回归 (Ridge Regression with Polynomial Features)**：

1. **特征扩展**：给定输入向量 $X = [x_1, x_2, \dots, x_d]$，将其显式展开为一个包含了常数项、一次项、平方项以及所有两两交叉项的扩展向量 $\Phi(X)$：

$$
\Phi(X) = \big[1, \underbrace{x_1, \dots, x_d}_{\text{一次项}}, \underbrace{x_1^2, \dots, x_d^2}_{\text{平方项}}, \underbrace{x_1 x_2, x_1 x_3, \dots, x_{d-1} x_d}_{\text{交叉项}}\big]
$$

经过扩展后，原始 $d$ 维特征变为了 $D = 1 + 2d + \frac{d(d-1)}{2}$ 维。

2. **闭式求解 (Closed-Form)**：在训练阶段，给定采集到的 $N$ 个样本构成的特征矩阵 $\Phi_{N \times D}$ 和目标列向量 $Y$，直接通过解析公式求解带有 L2 正则化系数 $\alpha$ 的最优权重列向量 $W$：

$$
W = (\Phi^T \Phi + \alpha I)^{-1} \Phi^T Y
$$

3. **极速推理**：在寻优阶段的预测，就是将新输入的特征扩展后，与固定权重向量 $W$ 算一个简单的内积（点乘）：

$$
Y_{pred} = \Phi(X) \cdot W = w_0 + \sum_{i=1}^{d} w_i x_i + \sum_{i=1}^{d} w_{ii} x_i^2 + \sum_{i=1}^{d-1} \sum_{j=i+1}^{d} w_{ij} x_i x_j
$$

用这批收集到的数据，我们通过上述闭式公式一次性算出了两个纯白盒的代理模型权重：

- **Model A（物理特征代理，负责指路）**：
  - **结构**：`输入 d=7 (Tx 7-tap FIR) -> 展开为 36 维特征 -> 乘权重 -> 输出 (log10 BER)`
  - **训练方式**：使用 `tx_channel_extract.py` 提取发端通过 DAC 和模拟前端后的物理等效冲激响应作为输入特征。
  - **作用**：提取发端均衡配置与最终眼图质量之间的内在单调规律。在 Stage 2 中，我们对 Model A 求解梯度，它会明确告诉我们“向哪个方向调整 FIR 形状能让 BER 下降最快”。
- **Model B（系数安全代理，负责护航）**：
  - **结构**：`输入 d=10 (FFE 9-tap 系数 + CTLE) -> 展开为 66 维特征 -> 乘权重 -> 输出 (log10 BER)`
  - **训练方式**：直接从原始 10 维系数映射到 BER。
  - **作用**：作为 Stage 2 步进时的安全底线防线。由于它是直接从系数预测的，它可以防止优化器提出一些虽然 FIR 形状看似不错、但会导致实际物理系数爆表从而引发掉锁的极端假解。

### Stage 2: 带约束的快速梯度下降 (PGD)
进入 Stage 2，我们**彻底切断了真实的 MLSE_BER 反馈**。

我们从起点 `x0` 出发，按照以下逻辑进行手写投影梯度下降 (Projected Gradient Descent)：
1. **代理求导**：在 Model A 上使用有限差分计算 10 维梯度。因为 Model A 的推断只是极其简单的数学闭式运算，这个求导过程在**毫秒级**完成。
2. **线搜索安全检查**：沿着负梯度方向，先走一大步，把新系数丢给 Model B。如果 Model B 预测这个点会发生严重恶化（超出相对安全阈值），就回退一半步长继续查，直到 Model B 亮绿灯。这相当于在虚拟数学曲面上“摸石子过河”。
3. **闭环更新**：走到新点后，更新坐标。在整个算法决策层，不需要跑任何一次真实的物理信道验证。

> [!NOTE]
> 在我们的验证脚本（如 `test_generalization.py`）中，你依然会看到真实 BER 被缓慢地打印出来。这仅仅是为了向用户**验证并记录算法确实走在正确的路上**而进行的旁路抽检，这个极其耗时的真实值**绝对不参与下一个梯度的决策运算**。在实际工程部署中，旁路打印将被移除，寻优过程将变为瞬间收敛。

## 3. 免重训的跨环境泛化性

最神奇的一点在于：一旦特征代理模型 (Model A) 学习到了 `Tx FIR -> 眼图质量` 的单调对应关系，这种关系在面临**物理损伤平移**时依然极其稳健。

我们在验证测试中证明了，拿着在 26.5 dB (无额外色散) 训练出来的同一套 Model A 和 B，直接放到 28.0 dB (1e-5 深水区)、并施加极端的色散 (CD 15ps/nm) 与偏振模色散 (DGD 5ps，及各种偏振态 SOP) 下，模型**不需要重训任何权重**，就能在全新的恶劣工况中，稳定且精确地指出最优的下降方向。这实现了**真正的“一次训练，动态泛化”**。

## 4. 为什么跨环境不需要加绝对值校准层？
跨环境（如跨 SNR 或引入色散）时，Model A 预测出来的“绝对 BER 值”必然会和深水区真实的 BER 对不上（预测值偏高）。为什么算法中不需要加一层多层感知机进行校准？
1. **梯度下降只依赖“相对单调性”**：Stage 2 优化器使用的是梯度的**方向** (`g/|g|`)。无论绝对底噪怎么上下平移，只要单调性（即改变系数使得眼图变好还是变坏）没被颠覆，算出来的最陡下降方向就永远是对的。
2. **Model B 的动态红线**：Model B 判断安全的标准是“新配置预测出的 BER ≤ 种子点预测出的 BER + 阈值”。这是一种动态的相对检查机制，天然抵消了跨环境导致的全局基线漂移。
