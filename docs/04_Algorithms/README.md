# 核心寻优算法全景图 (Optimization Algorithms Panorama)

[返回项目主页](../../README.md)

本项目定位为底层硬件算法的原型验证，核心宗旨是彻底拒绝将算法细节封装隐藏的“黑盒”。

> [!IMPORTANT]
> **Live Tuning (在线硬调) 的绝对红线**
> 在真实的 112G/224G 光电链路在线调优中，任何探索行为如果导致测试误码率突破 $10^{-2}$，将引发硬件纠错码 (FEC) 击穿与物理链路“掉锁”。
> 所有的离线大范围探索算法（如传统 GA、SA、标准 BO）在在线环境中均具有极高的坠崖断链风险，我们必须设计带有严格物理安全约束的新型算法。

为应对离线寻优与在线硬调的不同场景需求，本目录对现有算法进行了分类梳理：

## 1. 终极两阶段离线架构 (Two-Stage DDPS)
这是针对 LPO 链路极为苛刻的防掉锁要求所设计，并最终进化完成的完全离线架构方案。

👉 **[DDPS 数据驱动物理代理优化器 (Data-Driven Physical Surrogate)](DDPS.md)**  **(当前核心服役)**
**当前状态**：核心服役中 | **代码路径**：`ddps_optimizer.py`  
**简介**：完全离线的“数据驱动”终极路线。Stage 1 在安全区进行拉丁超立方采样 (LHS)，训练出纯数学的二阶多项式 Ridge 回归代理模型（Model A 提取发端物理 FIR 作为预测特征，Model B 提取系数作为安全约束）。Stage 2 彻底切断真实 BER 回传，完全在 Model A 上使用有限差分计算 10 维物理梯度，并进行带 Model B 安全约束的投影梯度下降。真正实现了“毫秒级算梯度，零物理试错”，是在极限物理插损与高色散环境下的唯一真神。

## 2. 历史架构与原型库 (Archived)
**注：以下所有古典优化器及早期演化版本均已从主线移除，统一封存于根目录的 `archive/` 文件夹下，仅供历史参考与技术沉淀。**

这些是在探索防掉锁架构过程中留下的珍贵原型机。它们为 DDPS 的最终形态提供了宝贵的避坑经验与数据积累。

👉 **[TuRBO-Safe (推荐极品)](../../archive/TuRBO_Safe.md)**  
**简介**：通过贝叶斯模型 ($3\sigma$ 置信度) 与动态信任域的结合，曾能够同时满足严苛安全限制与全局最优深度的单体生产级方案。

👉 **[SafeQCD (数学微探针方案)](../../archive/SafeQCD.md)**  
**简介**：纯数学推导的二阶优化器。改用微小摄动探测局部梯度与曲率，并通过抛物线方程精确计算悬崖边界。

👉 **[第一代在线两阶段优化 (Two-Stage Online Optimization)](../../archive/Two_Stage_Optimization.md)**  
**简介**：DDPS 的前身。第一阶段采用 BO_Safe，第二阶段采用提取眼图统计特征的 GPR (高斯过程回归) 作为代理。

👉 **[Surrogate_SHC (代理辅助爬山)](../../archive/Surrogate_SHC.md)**  
**简介**：早期的代理辅助爬山算法。通过代理记忆模型在物理下发前进行数学推演，主动规避历史危险点。

👉 **[传统基线算法详解 (SHC / GA / SA / ESC)](../../archive/Baselines.md)**
- **SHC**：工业界最原始的步进退避爬山法，无预判能力。
- **ESC_Safe**：基于连续 Dither 的梯度解调，极易被信道噪声淹没跑飞。
- **GA**：全局演化王者，但变异跃迁会直接引发物理断链。
- **SA**：带概率接受机制的局部退火，高温期等同于随机送死。
