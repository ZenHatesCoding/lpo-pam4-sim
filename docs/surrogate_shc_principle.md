# Surrogate-Assisted Safe Hill Climbing (代理模型辅助安全爬山算法) 原理解析

[返回主页](../README.md)

## 1. 算法背景
本项目核心要求之一是“物理代价忠实记录”。在线调优 (Online Tuning) 过程中，如果使用纯盲搜算法（如标准的 SHC），算法为了探路会随机往一个方向迈步；一旦该方向是“悬崖”（例如眼图余量极小），真实的硬件链路就会爆出极高的 BER，甚至触发重新握手（掉锁）。这种物理试错代价在现网中是不可接受的。

为了解决这个问题，我们不能仅仅依靠事后的“知错能改”（Regression 退避），而必须做到**事前预测、规避悬崖**。由于我们严格遵循**白盒化**设计，不引入黑盒高阶库（如完整的贝叶斯优化包），我们自研了 Surrogate-Assisted SHC。

## 2. 核心原理：IDW 代理模型与安全过滤

本算法在每次物理下发系数前，会在“大脑”里先进行模拟推演。

### 2.1 逆距离权重 (Inverse Distance Weighting, IDW)
由于 BER 曲面是高度非线性的，简单的线性回归（如 Ridge Regression）容易陷入局部误判（比如误以为越过一个深坑后是平原）。因此，我们采用距离反比权重（IDW）算法。
对于一个给定的试探步 $x$，我们预测其性能 $y_{pred}(x)$：

$$ y_{pred}(x) = \frac{\sum w_i y_i}{\sum w_i} + P_{unc}(x) $$

其中：
- $y_i$ 是滑动窗口（默认最近 50 次物理下发）中记录的历史真实 BER。
- $w_i = \frac{1}{||x - x_i||^2 + \epsilon}$ 是距离的平方反比。
- $P_{unc}(x) = \alpha \frac{\min(||x - x_i||)}{\text{StepSize}}$ 是**不确定性惩罚项**（Uncertainty Penalty）。如果该试探步远离所有已知的安全点，惩罚项会直接拉高预测代价。

**安全保证的核心逻辑**：如果候选解靠近历史的“危险点”，$y_{pred}$ 会因为距离极小导致权重无穷大而被直接判定为危险；如果候选解试图跳跃到未知领域，$P_{unc}$ 会因距离惩罚而拉响警报。

### 2.2 冷启动微步防御 (Warmup Defense)
在优化刚启动、历史记录不足以建立模型时，算法强制进入“微步模式”。此时探索步幅被强制缩小为正常情况的 $1/5$ (20%)，仅改变单个坐标轴进行安全的梯度试探，直到窗口被填入基础数据，彻底消灭初期的盲搜风险。

### 2.3 “20 次逻辑试探，1 次物理下发”
在得到上述预测能力后，算法每回合会在数学空间中产生 20 次随机候选步。它只会挑出**第一个在预测模型中低于安全红线（例如 $BER < 10^{-2}$）**的步进下发物理执行。如果 20 次尝试全部被预测为“危险”，它绝不会头铁强上，而是主动退避，发出一个步幅仅为原本 10% 的极其微弱的探路针。

## 3. 付出的计算代价 (Computational Cost)

由于我们坚持“极简数据流”，该方案无需计算海量的高斯过程逆矩阵（$O(N^3)$），只需进行简单的矩阵距离运算：

- 算法维护一个容量为 $N=50$ 的滑动窗口。
- 设待调优参数维度为 $D=12$。每次迭代需在逻辑层推演 20 个候选解。
- 每次推演需要计算 $N$ 个已知点的欧氏距离，复杂度为 $O(N \times D)$。
- 20 次推演的总计算量约为 12,000 次浮点乘加运算（Flops）。

这对于现代 DSP/CPU 而言，耗时处于微秒 (us) 级别，完全可以无缝嵌入在线调优周期中（通常间隔秒级或毫秒级）。用极小的本地计算算力，换取了绝对的链路不掉锁保证，收益巨大。
