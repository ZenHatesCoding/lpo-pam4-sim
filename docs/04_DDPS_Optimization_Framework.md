# 04. DDPS 数据驱动物理代理寻优框架
[🔙 返回主页](../README.md)

在高速 LPO（Linear Pluggable Optics）系统中，信道极度受限且不允许使用长 DFE，系统寻优面临巨大的高维非凸挑战。为解决极高维度寻优慢、易陷入局部最优的问题，本平台原创了 **DDPS (Data-Driven Physical Surrogate)** 双层代理寻优架构。

该架构的宗旨是：**在绝不在真实硬件上进行随机试错破坏的前提下，通过完全脱机的内存“沙盘推演”，利用机器学习寻找收发端联合最优解。**

---

## 1. 核心理论：发射端波形的等效坍缩（白盒探针）

直接将 DSP 和模拟硬件配置（如 FFE 抽头权重、CTLE 增益）丢给黑盒深度学习网络进行回归，会导致严重的“泛化灾难”。机器学习无法凭空内化复杂的微波传输线理论、S参数曲线衰减和频率响应公式。

因此，我们引入了 `tx_channel_extract.py` 作为**发端物理探针**。

### 探针机制：
探针向系统发送一个理想的数字单位脉冲（Dirac Delta，即 `...0, 0, 1, 0, 0...`）。该脉冲随后穿过：
- 数字 Tx FFE
- DAC 零阶保持器 (ZOH)
- **模拟 Tx CTLE (支持双零点/双级增益)**
- 宿主机 PCB 走线 (包含 S 参数带内衰减)
- 电光调制器低通滤波

在这套微波/DSP物理公式运算结束后，探针在打入光纤前将其捕获，并对齐截取出 7-tap 的等效数字 FIR。这个 7-tap FIR 就是当前这组配置对应的**最终物理真实发射波形**。

这一步将复杂的硬件参数等效折算（坍缩）成了纯粹的发射端冲激响应。

---

## 2. Model A 与 Model B 的双路护航

有了探针做物理公式的前置计算，我们就能让 ML 模型变得非常轻量且极具泛化性。我们通过离线采样（Stage 1），训练了两个白盒代理模型。

### 2.1 寻优主代理：Model A (Ridge 脊回归)
- **输入**：由探针算出的 7-tap 等效 FIR 波形。
- **输出**：预测的 `log10(MLSE_BER)`。
- **价值**：因为复杂的频率响应已经被探针解完了，Model A 只需要学习一个非常简单的线性映射：“发出去的波形长什么样” -> “收端的 BER 有多好”。这使得 Model A 即便面对从未见过的信道损伤（更高的插损、色散），也能极其精准地通过计算给出波形优化的梯度指向，真正实现**零次重训（Zero-Shot）**泛化。

### 2.2 安全把关代理：Model B (多项式回归)
- **输入**：直接的原始配置参数，即 `[8个FFE] + [gDC] + [gDC2]`（完整的 10D 空间）。
- **输出**：预测的 `log10(MLSE_BER)`。
- **价值**：Model B 不走物理探针，直接进行全局映射。它的作用是在梯度下降中充当“刹车”。当优化算法给出一组新的配置时，Model B 负责评估这组参数是否会掉落到断崖式劣化的差解区（防止硬件掉锁）。

---

## 3. 沙盘推演：Stage 2 约束梯度下降

DDPS 优化的第二阶段（Stage 2）是一个不碰真实硬件的脱机微操过程，由 `ddps_optimizer.py` 驱动。

1. **数值梯度提取 (Numeric Gradient)**：
   对 10 个控制维度（FFE + CTLE 参数），逐一施加有限差分微扰（例如 `+1e-4`），利用探针加上 Model A 算出偏导数，得到 10D 梯度向量。该梯度明确指示了：如何修改 FFE 和 CTLE 才能把发射波形整形成 Model A 认为最优的形态。
   
2. **约束线搜索 (Constrained Line Search)**：
   沿着负梯度方向给出一个候选组合。此时**严禁**直接采纳，而是将候选参数喂给 Model B 进行安全审查：
   - 若 Model B 判定候选点超出了安全底线（BER 大于阈值），则将步长折半重试。
   - 若安全，则采纳，并在新位置继续计算梯度。

3. **Zero-Emission 寻优**：
   以上提取梯度、线搜索、安全把关的全套动作会在代码里迭代 20~25 次。因为只需调取 Ridge 模型预测，瞬间即可算完。25步之后拿到的最优解，直接下发给底层硬件进行最终验证（One-Shot 收敛）。

---

## 4. 彻底拥抱标准的 10D CTLE 升维

在早期的模型中，CTLE 仅抽象了一个直流增益参数（9D 寻优空间），硬编码了零点频率。这导致模型在面对 10dB~12dB 的高插损信道时，缺少调整高频 Peaking 的自由度。

当前架构已经**完全遵照 IEEE 802.3ck 与 LPO MSA v1.01 规范**进行了升维升级：
- `apply_ctle` 引入了完整的双级增益公式（基于双极点+多零点结构）。
- DDPS 状态空间从 9D 升级为 **10D**：即 8个主次 FFE Tap，加上高频增益 **`gDC`**，加上低频增益 **`gDC2`**。
- `tx_channel_extract` 与 `dataset_generator` 全量适配了这 10 个自由度的拉丁超立方正交采样，使得在极端恶化信道中，系统能完全依赖双向 CTLE 和 FFE 的配合找回被吃掉的高频能量。
