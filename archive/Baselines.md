# 传统基线与参考组 (Baselines)

[返回算法总览](README.md)

> [!WARNING]
> 以下算法皆为传统的全局优化或局部优化基线模型。虽然它们在解决无限资源的纯数学寻优问题上非常强大，但由于**没有任何事前安全预测能力**，在 LPO 链路在线环境（Live Tuning）中具有极高的坠崖断链风险。本模块保留这些算法，仅作为纯离线评估与极端对照组使用。

## 1. Safe Hill Climbing (SHC)
最原始的工业界安全爬山法。
- **机制**：完全依靠“事后诸葛亮”机制：随机步进 -> 物理测试 -> 变差则退回，变好则接受。
- **评价**：在测试前没有任何模型预判能力，如果处于陡峭山崖边，一脚踏空就会导致系统瞬间爆误码、掉锁。
- **评估表现**：收敛深度极佳 (`Best MLSE = 3.76e-05`)，但在盲搜过程中频繁引发严重断链 (Max MLSE 达到 `3.63e-02`)。
- **代码位置**：[`shc_optimizer.py`](../../shc_optimizer.py)
- **调用方式**：在 `config.xlsx` 设置 `optimizer_type = 'SHC'`

## 2. Extremum Seeking Control (ESC_Safe)
基于抖动信号（Dither）的极值搜索控制。
- **机制**：通过在 FFE 权重上叠加高频微小的正弦波抖动，利用相敏检波提取出目标函数的近似梯度。
- **评价**：理论优美但在恶劣的高频带噪链路中，Dither 的微弱能量极易被底噪淹没，提取的梯度形同抛硬币。实测中方向跑偏极为严重，且极易陷入震荡。
- **评估表现**：最大误码率达到 `1.85e-01`，且完全无法收敛。
- **代码位置**：[`esc_optimizer.py`](../../esc_optimizer.py)
- **调用方式**：在 `config.xlsx` 设置 `optimizer_type = 'ESC_Safe'`

## 3. 遗传算法 (Genetic Algorithm, GA)
经典的元启发式演化算法。
- **机制**：基于种群的锦标赛交叉与多点高斯变异，用于大范围连续演化。
- **评价**：全局搜索的王者，但代价是每次变异跃迁都是一次盲跳深渊，对于不能承受单次恶劣代价的 Live 场景是灾难性的。
- **代码位置**：[`ga_optimizer.py`](../../ga_optimizer.py)
- **调用方式**：在 `config.xlsx` 设置 `optimizer_type = 'GA'`

## 4. 模拟退火 (Simulated Annealing, SA)
带激进退温机制的随机搜索。
- **机制**：局部抖动探索，利用 Metropolis 准则在前期高温时接受恶化的解，以图跳出局部最优。
- **评价**：主动拥抱恶化以换取探索空间，这一设计初衷直接违背了硬件环境“绝不允许坠崖”的核心底线。
- **代码位置**：[`sa_optimizer.py`](../../sa_optimizer.py)
- **调用方式**：在 `config.xlsx` 设置 `optimizer_type = 'SA'`
