# Safe Quadratic Coordinate Descent (Safe QCD)

[返回算法总览](README.md)

> [!NOTE]
> 本文档说明了本项目在寻找“绝对安全的在线调优算法”过程中，从“一阶盲搜与代理预测模型”转向“二阶抛物线确定性模型”的原理革命。它是本项目防御物理坠崖的一种纯数学解法。

## 1. 原理与方案设计 (Principle & Scheme)

### 为什么放弃纯一阶代理预测？
我们曾试图用机器学习中的代理模型来预测信道悬崖。但在高速 DSP 参数空间中，不同维度的敏感度差异极大（例如 CTLE 与 FFE 的敏感度差异超过 5 倍），且悬崖极其陡峭。当探索步幅越过当前安全边界时，纯代理模型极易因错误插值给出致命误判，导致 `Max BER` 大幅恶化。

### 二阶抛物线物理级防御
为了实现零侥幸的 100% 安全保证，算法降维打击，采用了基于微探针的二阶曲率感知 (Hessian-Aware) 原理。

1. **微距测绘 (Micro-Probe)**
   在某个维度 $x$ 寻找下降方向时，不进行盲目大步尝试。而是先在当前点 $x_0$ 强制打出 $+0.01$ 和 $-0.01$ 的极微小探针。
   由于步幅极小，探测引发的 BER 劣化被硬性约束在物理安全极限内。
2. **二次抛物线拟合 (Parabolic Interpolation)**
   获得三个物理点后，直接解出一元二次方程 $y(x) = ax^2 + bx + c$：
   - 曲率 $a$，代表信道敏感度（Hessian 矩阵对角元）。
   - 梯度 $b$，代表信道倾斜度。
3. **悬崖根部精确求解 (Safety Roots)**
   已知安全红线为 $Y_{max} = \log(10^{-2})$。
   通过求解 $ax^2 + bx + c = Y_{max}$，可以直接用求根公式精确算出：往前走多少绝对距离会掉进悬崖。
4. **受限跳跃 (Bounded Optimal Jump)**
   算法欲将参数跳跃至抛物线谷底 $x^* = -\frac{b}{2a}$，但必须受上述求出的安全根严格钳制 (Clip)。面对陡峭悬崖（$a$ 大）自动碎步，面对平原（$a$ 小）自动大跨步。

## 3. 测试方法与结果 (Test Method & Results)

### 测试方法
执行统一脚本 `compare_optimizers.py` 进行硬核物理试错，并观测安全截断能力。

### 结果客观指标
在恶劣测试（1M 符号，28.0dB，25 次评估）中：
- **Max MLSE BER (安全性)**：探索期间最大误码被绝对锁死在 `6.74e-03`，表现出无可匹敌的绝对稳定性。
- **Best MLSE BER (寻优深度)**：收敛于 `1.15e-03`。由于二阶抛物线无法跨越复杂地貌的鞍点，它容易被局部欺骗卡在次优解，寻优深度落后于后期的 TuRBO-Safe。

## 4. 用法 (Usage)

在主仿真入口 `main.py` 或 `optimize_tx.py` 运行时，通过全局配置文件 `config.xlsx` 控制：
- 在 `tx` 表格中，设置 `optimizer_type = 'SafeQCD'`。
- 参数 `probe_delta` 定义了极小探针的步长，默认 `0.01` 即可保证试探动作的绝对安全。
