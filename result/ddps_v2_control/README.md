# 对照实验：单环境训练模型（Base_IL10 only）

> 目的（AGENTS.md 控制变量法）：只把**基准环境 Base_IL10** 的邻域数据给训练（`models/ddps_v2_control/`），再冻结复用到全部 8 个应力环境做 Stage-2 在线调优 —— 回答"单点模型能否直接泛化、是否必须混合环境"。

## 结果

| 用例 | 种子 BER_MLSE | 最优 | Δlog10 | 步数 |
| --- | --- | --- | --- | --- |
| Base_IL10 | `5.53e-04` | `3.55e-04` | `-0.19` | 25 |
| IL_Sweep_14dB | `2.08e-03` | `5.49e-04` | `-0.58` | 25 |
| IL_Worst_20dB | `5.82e-02` | `1.47e-02` | `-0.60` | 25 |
| CD_Sweep_15ps | `6.57e-04` | `3.55e-04` | `-0.27` | 25 |
| CD_Sweep_28ps | `6.94e-04` | `3.55e-04` | `-0.29` | 25 |
| DGD_Sweep_2ps | `4.42e-04` | `3.55e-04` | `-0.09` | 25 |
| DGD_Sweep_5ps | `4.71e-04` | `3.59e-04` | `-0.12` | 25 |
| Combined_Stress | `7.72e-02` | `3.48e-02` | `-0.35` | 25 |

## 与主实验（混合环境锚定）对比结论

- 修复后的管线**即使只用基准环境数据训练，8/8 用例也不再负向优化**（对比 v1 同场景是负向的）。
- 但在 20 dB 插损 / 复合应力等极端环境，单环境模型的外推明显衰减：主实验最优 IL20 `2.97e-3` vs 对照 `1.47e-2`；Combined `5.74e-3` vs `3.48e-2`。即：物理噪声主导下，**需要混合环境数据**才能把高应力用例调到位。
