## 4. 架构（v6：A=探针->BER，B=参数->BER）

**Model A（方向代理）**：输入 = [7-tap Tx FIR 探针, drive_rms]（8 维波形域）
-> log10(BER_MLSE) 条件均值。在线调优时拿不到收端 BER，只能拿发端探针，
所以 A 建立发端探针到收端 BER 的方向映射。梯度通过链式法则：扰动 6 维参数
-> 重算探针 -> 查 A -> 得 ΔBER（6 维中心差分）。

**Model B（风险控制）**：输入 = [4 FFE 旁瓣, gDC, gDC2, drive_rms]（7 维参数域）
-> log10(BER_MLSE) 保守上包络。按变差百分比拒绝候选，理想情况全程不触发。

**A/B 输入空间不同**（波形域 vs 参数域），误差来源相互独立。

**gain 维**：不在 A/B 输入里。每个用例单独细粒度扫描标定 target_rms
（0.06~0.22V，步长 0.005），在线调优时每步解析调到该用例的 target_rms：
gain = gain_ref × (target_rms / rms_measured)。解析出的 gain 倍率自动从
强信号环境的 ~0.6 调到弱信号环境的 ~1.3——即"锁定发端 RMS 给每个用例配 gain"。
