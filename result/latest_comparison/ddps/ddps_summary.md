# DDPS 数据驱动物理代理优化器 — 结果报告

- **模式**：112G PAM4（56 GBd），SNR 28.0 dB，1,048,576 Symbols（DEEP_1E5）
- **热身保真度**：SNR 26.5 dB / 65,536 Symbols（用于邻域采样与主动学习）
- **种子点**：两阶段实验的“初始次优点”，热身 MLSE `1.69e-03`，深水 MLSE `1.44e-03`
- **邻域采样**：600 样本（FFE ±0.05 / CTLE ±3 dB）+ 1000 全局覆盖样本

## 代理质量

| 代理 | 特征 | 测试集 R² |
| --- | --- | --- |
| Model A（物理代理） | 发端 7-tap 等效 FIR | `0.720` |
| Model B（配置代理） | FFE 9-tap + CTLE | `0.913` |

## 收敛结果（同口径深水校验）

| 方案 | MLSE BER | 相对种子点 |
| --- | --- | --- |
| 种子点（初始次优） | `1.44e-03` | 1× |
| **DDPS（9D）** | **`4.81e-05`** | **30× 提升** |
| SHC 参考（9D） | `3.76e-05` | — |
| SHC 参考（12D, fp2=0.9） | `3.76e-05` | — |

## 最优解

- **Tx FFE Taps**：`[-0.0022, -0.0069, 0.0628, 0.0043, 0.8835, 0.0215, -0.0019, -0.0052, 0.0116]`
- **CTLE DC Gain**：`-0.237 dB`

## 关键结论

DDPS 在**完全离线**、仅依赖发端物理 FIR 代理 + SLSQP 的情况下，从次优点 `1.44e-03` 收敛到
`4.81e-05`，与 SHC 基线（`3.76e-05`）同量级（1.3× 以内），验证了“数据驱动物理代理”路线的可行性。
