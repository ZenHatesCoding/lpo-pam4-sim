# DDPS 数据驱动物理代理优化器 — 结果报告

- **模式**：112G PAM4（56 GBd）
- **热身保真度**：SNR 26.5 dB / 65,536 Symbols（Stage 1 采样 + Stage 2 下降）
- **深水校验**：SNR 28.0 dB / 1,048,576 Symbols（DEEP_1E5）

## 架构

- **Stage 1（模型供给）**：起点邻域采样，训练 Model A（发端 7-tap FIR → logBER）与
  Model B（配置 → logBER）。产出 = 起点 + 双模型，不追求穷尽地形。
- **Stage 2（约束下降）**：在 Model A 上做 SLSQP 梯度下降，Model B 作安全不等式约束 + 信任域；
  **不回传真实 MLSE_BER**（仅记录验证）。

## 关键指标

| 指标 | 数值 |
| --- | --- |
| 起点 x0 真实 MLSE | `1.69e-03` |
| Stage 1 采样最优 MLSE | `2.05e-03` |
| **Stage 2 最优 MLSE（不回传）** | **`8.82e-04`** |
| Stage 2 最大 MLSE（安全上限） | `9.27e-04` |
| 等效性 Spearman(ModelA, real logBER) | `0.575` |
| 最优 Taps | `[-0.0064, -0.0079, -0.0028, -0.1987, 0.7206, 0.0321, 0.0293, -0.0, -0.0023]` |
| 最优 CTLE DC | `-0.000 dB` |

## 跨 SNR 迁移（26.5 dB 模型引导 28 dB 下降）

| step | 26.5dB MLSE | 28dB MLSE |
| --- | --- | --- |
| 0 | `8.82e-04` | `8.95e-05` |
| 6 | `8.82e-04` | `1.84e-04` |
| 12 | `8.82e-04` | `1.84e-04` |
| 18 | `8.82e-04` | `1.84e-04` |
| 24 | `8.82e-04` | `1.84e-04` |

> 结论：26.5 dB 模型能把下降带进“对的盆地”（区域级迁移成立），但盆地内部 28 dB 的精细分化
> （`8.95e-05` vs `1.84e-04`）无法由 26.5 dB 模型分辨（精细级不可迁移）。
