## 4. 架构（v6.2：A=探针->BER，B=参数->BER）

**Model A（方向代理）**：输入 = [7-tap Tx FIR 探针, drive_rms]（8 维波形域）
-> log10(BER_MLSE) 条件均值。在线调优时拿不到收端 BER，只能拿发端探针，
所以 A 建立发端探针到收端 BER 的方向映射。梯度通过链式法则：扰动7 维参数（4 FFE 旁瓣 + gDC + gDC2 + u_gain）
-> 重算探针 -> 查 A -> 得 ΔBER（中心差分）。

**Model B（风险控制）**：输入 = [4 FFE 旁瓣, gDC, gDC2, drive_rms]（7 维参数域）
-> log10(BER_MLSE) 保守上包络。按变差百分比拒绝候选，理想情况全程不触发。

**A/B 输入空间不同**（波形域 vs 参数域），误差来源相互独立。

**gain 维**：通过 drive_rms 进入 A/B 输入，作为第 7 维走链式梯度。初值 = 每个用例
单独扫描标定的最优 gain（per-case target_rms -> 解析 gain），信任域 ±0.15 dex，
之后放开让 gain 在梯度下降里继续优化。
